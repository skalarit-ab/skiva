# Changelog

Each release's section is its notes on GitHub, and what Skiva's update
window shows as new. See RELEASING.md.

## v0.2.0-beta.1

The first desktop release, for Windows and Linux.

- The downloaded program installs Skiva for you, with no administrator,
  and offers to open MP3, FLAC, Ogg Vorbis and WAV files with it.
- A file opened with Skiva plays at once. Several opened together play
  one after another.
- Settings, in the library's menu, set how updates come: automatically,
  after asking, or not at all. Betas come too if you ask for them.
- The installed Skiva keeps itself up to date, and runs only updates
  signed by Skalarit.
